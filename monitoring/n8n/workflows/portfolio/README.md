|---|---|
| 원본 | [`../n8n_경로_실사용URL_적용.json`](../n8n_경로_실사용URL_적용.json) — **김준오(D, 관제·자동화) 작성, 수정하지 않음** |
| 수정본 | [`n8n_경로_실사용URL_적용_로컬재현.json`](n8n_경로_실사용URL_적용_로컬재현.json) — 김준식이 노트북 한 대에서 재현하려고 고친 사본 |
| 로컬 주소판 | `python scripts/localize_monitoring.py` → `monitoring/local/n8n/portfolio/` (n8n 에는 이 파일을 가져온다) |

## 원본과 다른 곳

| # | 노드 | 원본 | 수정본 | 이유 |
|---|---|---|---|---|
| 1 | 앱 API 를 부르는 HTTP 노드 10개 (`대시보드 POST1~…`) | 비활성, 본문 식 안에 `}}` | 활성, `}}` → `} }` | `}}` 가 n8n 식 `{{ … }}` 를 중간에서 닫아 `invalid syntax` 오류 |
| 2 | `판정(잠금)` (Code) | `username` 이 있는 경보만 처리 | `account_hash`(SHA-256 64자)도 처리 | 앱은 이메일 대신 `account_hash` 를 남긴다 (Graylog `ED-A1`) |
| 3 | `HTTP 계정 block 요청` | 비활성, 본문이 `$json` 을 읽음 | 활성, 본문이 `$('판정(잠금)').item.json` 을 읽음 | 이 노드는 인시던트 등록 노드 뒤에 붙어 있어 `$json` 이 등록 응답이었다 → 400 |
| 4 | 같은 노드 헤더 | — | `X-Workflow: 8-login-bruteforce` | 관리자 콘솔 '자동화 현황' 카드 이름과 맞춤 |
| 5 | 워크플로 이름 | 원본 이름 | 뒤에 `(로컬 재현 수정본 · 원본 김준오)` | 원본과 헷갈리지 않게 |

그 밖의 노드·연결·판정 규칙은 원본 그대로다. 비밀값(웹훅·토큰)은 원본과 같이 `{{ $env.… }}` 로 읽는다.

## 팀에 제안할 것

1·3번은 원본에도 있는 오류라, 학원망에서도 같은 노드를 켜면 같은 문제가 난다. 김준오 님께 이 표를 전달해 원본에 반영할지 정하면 된다.
